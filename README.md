# gsfeir.com

Personal academic website of Georges Sfeir, served by GitHub Pages.
Plain HTML, CSS and JavaScript. There is no build step: edit a file, commit, and the site updates in about a minute.

## Common edits

| What | File |
|---|---|
| Add a paper / move one from under review to published | `data/publications.js` (instructions at the top of the file) |
| Add or edit a project | `data/projects.js` |
| About me text, social links | `index.html` |
| Teaching and supervision | `teaching.html` |
| Update the CV | Replace `assets/cv/Georges_Sfeir_CV.pdf` (keep the same file name) |
| Photo | Replace `assets/img/georges-sfeir.jpg` |
| Menu items | `assets/js/site.js` |
| Colours and fonts | `assets/css/style.css` (variables at the top) |

## Editing on github.com

Open the file, click the pencil icon, make the change, then click **Commit changes**.
To replace a PDF or image: open its folder, click **Add file → Upload files**, upload a file with the same name, and commit.

## Preview locally

Open `index.html` in a browser. No server is needed.
